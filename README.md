# ⛏️ HashForge
### Built for South Africa. Optimized for low power.

HashForge is a lightweight, open-source mining toolkit designed for high Eskom rates and loadshedding conditions.

**What we mine:**
- **Kaspa (KAS)** - GPU mining, most profitable 2026
- **Monero (XMR)** - CPU mining, works on any laptop

**Why HashForge?**
- Pre-tuned for 150-200W (not 3000W Bitcoin miners)
- Auto-reconnect after loadshedding
- Eskom profit calculator included
- No fees, no scam, 100% open

**Quick Start:**
1. Download a miner (lolMiner for Kaspa, XMRig for Monero)
2. Use the config from `config.json`
3. Run `start-kaspa.bat` or `start-monero.bat`

**Pools:** WoolyPooly, 2Miners, SupportXMR
**Wallets:** Kaspa.org, Cake Wallet

> ⚠️ Check profitability at whattomine.com - Mining uses electricity. Calculate first.
